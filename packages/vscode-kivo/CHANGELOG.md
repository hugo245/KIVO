# Changelog

## 0.1.0

- KIVO language mode for `.kivo` files, with a dedicated file icon
- Syntax highlighting (keywords, strings with interpolation, numbers, comments, functions, classes, types, properties, operators)
- Bracket matching, auto-closing, auto-indentation, comment toggling, folding
- Live diagnostics from the KIVO checker (unknown names with suggestions, wrong argument counts, type mistakes, syntax errors)
- Autocomplete for keywords, built-ins, standard modules (with automatic imports), variables, functions, object properties and methods
- Hover documentation, signature help, go to definition, document outline
- Format Document using `kivo fmt`
- Run button and commands: Run File, Run and Restart on Changes, Check Project, Run Tests
